Browser Shell 人工测试中心

按卡片顺序点击即可，不需要 AI 操作。每项都写明了预期结果。

测试 Main / Preload 改动前，请完全退出并重新启动 Fan。仅刷新页面或等待热更新不会加载新逻辑。

1. 外部应用

模拟企业微信网页中的“打开微信”链接。建议先测取消，再重新点击测试打开。

请求打开微信 请求打开企业微信
预期：先出现 Fan 的说明弹窗。取消时不启动应用；选择“打开应用”后，才出现 macOS 的系统确认或启动对应应用。

2. 手动下载

下载一个本地生成的 3 MB 文件，服务端会故意分段发送，便于看到进度。

开始下载测试文件
预期：开始前不显示下载图标；点击后工具栏自动展开下载区并显示进度。完成后可“打开”或在 Finder 中显示；点击下载区右上角的叉后，下载区和工具栏图标一起消失，再次开始新下载时重新出现。

3. 网站 JS 弹窗

分别验证 alert、confirm 和 prompt，不应静默忽略，也不应让页面假装完成。

等待操作
预期：Fan 显示中文说明。confirm 的确定/取消、prompt 的输入内容会回显在上方结果框。

4. 页面权限

本地 localhost 可触发浏览器权限。建议先拒绝，再重新点击允许。

等待操作
预期：Fan 说明哪个页面请求什么权限，并提示“仅对当前页面有效”。刷新或离开再返回后，应重新询问。

5. 离开页面确认

先在文本框输入任意内容，使页面进入“有未保存内容”状态，再点击测试离开。

当前没有未保存内容
预期：出现“是否离开当前页面”。选择“留在此页”后页面不动；选择“离开页面”后重新加载，并显示已成功离开。

6. 新标签与自关闭

打开一个由页面创建的子标签，再在子标签中执行 window.close。

等待操作
预期：新标签受 Fan 管理；子标签可以关闭自己，原测试页不能被一起关闭。

  • 稳定与动态表单页
  • 测试站首页
