# Support

Use the public repository so answers remain searchable for other users.

## Report a bug

Open a [bug report](https://github.com/7757/Fan-Browser-Agent/issues/new?template=bug_report.yml) and include the Fan version, operating system and architecture, installation method, model provider, reproduction steps, and relevant error text.

Before attaching logs or screenshots, remove API keys, cookies, tokens, personal data, private URLs, and private page content.

## Request a feature

Open a [feature request](https://github.com/7757/Fan-Browser-Agent/issues/new?template=feature_request.yml) and explain the workflow you want to improve rather than only naming an implementation.

## Ask for help

Search [existing issues](https://github.com/7757/Fan-Browser-Agent/issues) first. If the problem is not covered, open a bug report and explain what you expected, what happened, and what you already tried.

## Report a vulnerability

Do not open a public issue. Follow the private reporting instructions in [SECURITY.md](SECURITY.md).
