# Fan 0.3.2：浏览器任务更稳，复杂对话更从容

Fan 0.3.2 集中打磨了复杂网页任务和持续对话的稳定性。Fan 现在能更可靠地理解页面并执行连续操作；当任务需要你补充信息或作出选择时，下一步也会更清楚地回到你手中。

## 复杂网页操作，更可靠

- 优化页面快照、内容提取和元素定位。在表单、列表及动态页面中，Fan 更容易找到正确的位置。
- 改进点击、输入和滚动后的状态检查，减少页面变化时重复操作、漏操作或操作落空的情况。
- 连续步骤较多时，浏览器任务会保留更完整的过程状态；发生中断后，更容易恢复和继续。

## 长任务协作，更清楚

- 加强长对话中的上下文整理和工具调用异常处理，让任务衔接更稳定。
- 需要确认、选择或补充信息时，会以更清晰的提示暂停等待，避免重要请求被淹没在对话中。
- 任务状态和反馈展示得到整理，让正在进行什么、下一步需要什么更容易判断。
