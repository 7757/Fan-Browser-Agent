# Fan 0.4.3 — 首个公开桌面发行版

这是 Fan-Browser-Agent 开源后的首个可直接下载安装的桌面发行版。它将 Electron 桌面界面、内嵌 Chromium 浏览器和本地 Python Agent 运行时打包在一起；启动后选择模型 Provider 并填写自己的 API Key 即可使用，不需要 Fan 产品账号。

## 下载

- **macOS Apple Silicon（M1/M2/M3/M4）**：下载 `Fan-0.4.3-mac-arm64.dmg`
- **macOS Intel**：下载 `Fan-0.4.3-mac-x64.dmg`
- **Windows x64**：推荐下载 `Fan-0.4.3-win-x64.exe`；也提供 MSI
- **Linux x64**：提供 AppImage、DEB 和 RPM

所有安装包旁边都提供 `SHA256SUMS.txt`，可用于校验下载文件。

## 这个版本包含

- 真实可见的内嵌浏览器与 human-in-the-loop 接管流程。
- DeepSeek、Alibaba、Coding Plan、Ollama Cloud 与自定义 OpenAI 兼容 Provider 配置。
- 本地 Skills、MCP、插件、定时任务、多任务工作区和本地持久化。
- GitHub Releases 更新源；Windows 和 Linux 支持应用内更新，macOS 会在发现新版本后打开对应 GitHub Release 页面下载安装。
- 移除 Fan SaaS 登录、账号门禁、消息平台投递和远程 Skills 市场依赖。

## 安装提示

0.4.3 暂未使用 Apple Developer ID 或 Windows 商业代码签名。macOS Gatekeeper 或 Windows SmartScreen 可能显示未知开发者提示；请只从本仓库的 GitHub Release 下载，并用 `SHA256SUMS.txt` 核对文件。后续版本会在签名基础设施就绪后补齐原生签名与公证。

# Fan 0.4.3 — First public desktop release

This is the first downloadable desktop release of the open-source Fan-Browser-Agent project. It bundles the Electron UI, embedded Chromium browser, and local Python agent runtime. Choose a model provider and enter your own API key on first launch; no Fan product account is required.

Download the DMG for Apple Silicon or Intel macOS, the NSIS installer (recommended) or MSI for Windows x64, and AppImage/DEB/RPM packages for Linux x64. Verify downloads against `SHA256SUMS.txt`.

Version 0.4.3 is not yet signed with an Apple Developer ID or a commercial Windows code-signing certificate, so the operating system may show an unknown-developer warning. Download only from this repository's GitHub Release. GitHub Releases is also the update source; macOS uses a manual installer handoff until signing and notarization are available.
