# Fan 0.4.3 — First public desktop release

Fan 0.4.3 is the first downloadable desktop release of the open-source Fan-Browser-Agent project. It bundles the Electron interface, embedded Chromium browser, and local Python agent runtime. Select a model provider and enter your own API key on first launch—no Fan product account is required.

> [!IMPORTANT]
> This preview release is not yet signed with an Apple Developer ID or a commercial Windows code-signing certificate. macOS Gatekeeper or Windows SmartScreen may display an unknown-developer warning. Download Fan only from this GitHub repository and verify the package with `SHA256SUMS.txt`.

## Downloads

- **macOS Apple Silicon (arm64):** `Fan-0.4.3-mac-arm64.dmg`
- **macOS Intel:** `Fan-0.4.3-mac-x64.dmg`
- **Windows x64:** `Fan-0.4.3-win-x64.exe` (recommended) or the MSI package
- **Linux x64:** AppImage, DEB, and RPM packages

## Highlights

- A visible embedded browser with human-in-the-loop takeover.
- Provider configuration for DeepSeek, Alibaba, Coding Plan, Ollama Cloud, and custom OpenAI-compatible endpoints.
- Local Skills, MCP, plugins, scheduled tasks, multi-task workspaces, and local persistence.
- GitHub Releases as the public update source. Windows and Linux support in-app updates; macOS opens the matching GitHub Release page until signing and notarization are available.
- Removal of the Fan SaaS login gate, account dependency, messaging-platform delivery, and remote Skills marketplace.

## Verify a download

Download `SHA256SUMS.txt` from this Release and compare the checksum of the installer before running it. For example:

```bash
sha256sum Fan-0.4.3-linux-x86_64.AppImage
```

On macOS, use `shasum -a 256 <downloaded-file>`. On Windows PowerShell, use `Get-FileHash <downloaded-file> -Algorithm SHA256`.
