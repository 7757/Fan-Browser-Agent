# Fan 0.4.0：原生浏览器更可靠，复杂任务衔接更自然

Fan 0.4.0 是一次面向原生浏览器工作台的重点升级。Fan 能更稳定地理解和操作网页；当登录、选择或确认等步骤需要你参与时，也会及时停下，把下一步清楚地交还给你。

## 复杂网页任务，更稳定地推进

- 改进页面快照、可访问性信息和内容提取。在复杂网站上，定位、点击、输入与滚动更可靠。
- 为连续多步骤任务优化执行与恢复机制；页面跳转、弹窗或短暂中断出现时，更容易保持上下文并继续推进。
- 优化页面变化和并发任务时的窗口管理，减少任务进行中的界面闪烁、遮挡或误触。

## 需要你参与时，边界更清楚

- 当任务需要确认、选择、密码或密钥时，Fan 会以明确的前台提示暂停等待，不会在后台悄悄遗漏请求。
- 发送、提交、付款、删除等关键动作仍需你的明确确认；Fan 会把页面证据和下一步操作留给你审阅。
- 原生浏览器与设置、命令中心等全屏界面的切换更平滑，通知与任务状态也更容易查看。

## macOS 安装与更新

- macOS 版本通过下载安装包进行安装和更新。
