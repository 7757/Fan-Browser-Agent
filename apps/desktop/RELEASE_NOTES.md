# Fan 0.4.3：浏览器接管更准确，多步骤任务更稳定

Fan 0.4.3 集中修复了真实网页任务中的状态漂移、误判接管和流程过早结束问题。Fan 现在会更可靠地依据最新页面继续操作，也能更准确地区分智能体操作与用户的真实接管。

## 页面理解与连续操作

- 保留简洁的三个浏览器入口，同时补齐底层浏览器能力的调用链；导航、点击、输入、下拉选择、上传、下载、标签页、截图和坐标操作仍可在连续工作流中使用。
- 在信息提交、人工验证、标签页切换和页面变化后重新读取当前页面，避免沿用旧观察结果或对失效元素继续操作。
- 只有当前页面存在真实、可操作的弹窗或验证挑战时才会进入处理流程，减少把普通页面内容、被动验证标记或历史状态误认成阻塞项。
- 改进表单、原生下拉框和文件上传的处理；密码等敏感值保持对模型不可见，同时确保浏览器收到用户实际提交的原值。

## 人机接管与恢复

- 只有用户真实点击、输入、滚动、切换标签页或使用地址栏时才触发接管；智能体自身的点击、滚动、页面动效和会话切换不再被误报为用户操作。
- 接管发生时立即暂停新的浏览器动作；点击“继续执行”后恢复工作标签页、读取最新页面，再从用户完成的位置继续。
- 浏览器操作光效覆盖任务开始、思考、执行和人工验证等待的完整周期，任务结束或明确停止后才消失。
- 连续无进展时会先更换策略并继续尝试，累计达到六次才停止，避免三步后直接把未完成任务交回用户。

## 权限与界面细节

- 麦克风、摄像头和位置权限仍由用户明确决定；其他常规网页权限默认自动处理，不再弹出额外权限窗口。
- 精简归档、通知和确认流程中的多余卡片及二级弹层，让暂停、空状态和结果提示更直接。

## macOS 安装与更新

- macOS 发现新版本时会打开安装包下载地址，由用户手动完成更新。
